# Shooter-3D
* **Inteligencia Artificial (IA):**
    * Uso de **NavMesh** y **NavMeshAgent** para la navegación de enemigos.
    * Implementación de una **Máquina de Estados Finitos (FSM)** para los comportamientos de los zombies (Patrulla, Persecución, Ataque).
* **Mecánicas de Juego (GameManager):**
    * Patrón **Singleton** para el control global del juego.
    * Sistema de **Win/Loss Conditions** (Victoria y Derrota) con gestión de tiempo (`Time.timeScale`).
* **Física y Combate:**
    * Detección de disparos mediante **Raycast**.
    * Sistema de salud y daño para jugador y enemigos.
* **Gráficos e Interfaz:**
    * Uso de **URP (Universal Render Pipeline)**.
    * Efectos visuales con materiales emisivos y Post-Processing (**Bloom**).
    * UI interactiva (Barra de vida, Pantallas de Fin de Juego).
